# ===== Transitive packages pinned to the tested build =====

# whatever is newest on the day of a build. They are pinned to the versions of

# and broke every Knowledge Base search and ingestion (transformers and tiktoken
# import regex). Native: regex, ormsgpack (langgraph's checkpoint serializer),
# jiter (openai). Pure Python, pinned because they moved in the same rebuild:
